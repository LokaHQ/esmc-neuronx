Sequence length: 512 (context window; 67% of sequences require windowing)
Compile:         regional (transformer blocks compiled individually)

Execution
---------
4 Docker workers, one per NeuronCore (cores 0–3), each processing a 1/4 shard.
Batch size per worker: 1
NEURON_LAUNCH_BLOCKING=1 set on all workers.

Initial full-graph compile (core 0, first run): 277 s
Cached compile/load (subsequent workers):       ~20 s mean
Model load (per worker):                        ~15 s mean

Results
-------
Parallel wall time:     568 s
Total samples:          125,190
Combined throughput:    220.3 samples/s  (wall-clock)
Sum worker steady-state: 239.2 samples/s
Per-worker throughput:  ~60 samples/s  (steady-state, batch=1)
Per-worker p50 latency: 15.2–15.3 ms  (per batch, batch=1 = per sample)

Quality
-------
ROC-AUC:             0.8525  (full dataset, labels reassembled from shards)
Average precision:   0.5992
Accuracy (t=0):      0.3939

Observations
------------
- Batch=1 with regional compile; each NeuronCore processes its shard independently.
- Regional compile (block-by-block) avoids the full-model graph complexity and
  produces a stable NEFF per transformer block (~20 s cached load).
- 4 independent NeuronCores scale linearly; no cross-core communication.
- Quality is essentially identical to CUDA RTX 5060 Ti baseline
  (ROC-AUC delta: +0.0001, average_precision delta: +0.0002).
